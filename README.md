# Celestial Bodies Database

Ein PostgreSQL-Datenbankprojekt, das Himmelskörper modelliert. 

Dieses Projekt demonstriert den sicheren Umgang mit relationalen Datenstrukturen, die Verknüpfung von Daten durch Primary und Foreign Keys sowie den gezielten Einsatz von Constraints, um die Datenintegrität sicherzustellen.
